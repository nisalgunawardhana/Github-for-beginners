## **What is the GitHub Foundations Certification?**

The GitHub Foundations certification is an official certification from GitHub. It validates your foundational knowledge of GitHub, including version control, repository management, collaboration workflows, and basic Git operations. This certification covers key topics like branching, merging, pull requests, and version history.

This exam is beginner-level and is aimed at anyone who wants to validate their understanding of the foundational topics, products, and concepts of collaborating, contributing, and working on GitHub.

The GitHub Foundations skills track was developed in collaboration with GitHub to help you pass the GitHub Foundations Certification. It covers topics like version control, collaboration, and branching — giving you hands-on experience across the topics the exam covers.
